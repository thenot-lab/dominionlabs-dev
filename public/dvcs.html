Dominion IDE

A development environment with AI built into it, that runs on your machine. No account, no telemetry, no code leaving your disk unless you send it. Bring your own model — a local one, or your own API key.

Download the installer

SHA-256 published beside the download so you can verify the file you got is the file we built.

Read this before you install

The installer is not code-signed yet. Windows SmartScreen will warn you and say the publisher is unknown — click More info → Run anyway if you choose to proceed. We would rather tell you that plainly than have you discover it at the prompt.

Signing certificates cost money we have not spent yet. When one is in place this notice comes down and the download is signed. Verify the SHA-256 in the meantime — that is the check that actually proves the bytes.

What it is

An editor, a terminal, and an AI agent that can read and change your project — in one desktop app.

Your model, your choice

Point it at a local model (Ollama) or your own provider key. The key stays on your machine.

Local first

Your files never leave the machine unless a request you made sends them. No background sync, no analytics.

Agent that acts

Reads the repo, proposes and applies edits, runs commands — with the diff in front of you before it lands.

Mobile companion

Pairs with the DVCS mobile app over mTLS on your own network — check a build from the couch.

Honest status

Version 2.2.0 is a real build from a test suite that runs green (1,655 passing) and a clean type-check — but it is early, and it is one person's work. It is offered as-is under active development. If something breaks, tell us and it gets looked at: contact@dominionlabs.dev.

Windows x64 only for now. macOS and Linux builds are possible but untested, and we would rather ship nothing than ship a binary we have not run.
