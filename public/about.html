★ about

Small shop. Real code. No fluff.

Dominion Labs is an independent shop. We make AI tools, run security audits, and build custom stuff for people who'd rather own their infrastructure than rent it.

What we actually do

Three things, mostly:

  • Ship tools. Open-source CLIs, miniapps you can use in the browser, companion apps. All listed on the home page. All free unless they cost real money to run.
  • Run audits. Real security assessments, not checklists. We read the code, find the actual problems, write you a report you can hand to a developer and they'll know what to fix.
  • Build custom. AI infrastructure on your hardware. Self-hosted setups. Automation. Companion apps. Whatever the project needs — if it's interesting and we can help, we'll quote it.

Why we started

Big tech AI keeps trying to put itself between you and your work. Subscriptions. Telemetry. Forced cloud. We started Dominion Labs to ship the opposite: tools that run on your own boxes, code you can audit, and a working pace that doesn't burn anyone out.

We're small on purpose. Small means we know each customer. Small means we say no to bad fits. Small means when you write to us, an actual person reads it.

How we work

  • Sovereignty first. Tools designed to run on your hardware. Your data stays with you. Cloud is optional, never required.
  • Open source where we can. Apache 2.0 license on most repos. Audit before you trust. Fork if you want to.
  • Plain talk. Honest scope, honest prices. No buzzwords. No upsells. No surprise invoices.
  • Ethics review. Every project gets a quick values check before any code gets written. Some asks we say no to.
  • Take. Build. Give back. Donations fund free engagements for non-profits and people who can't pay. The circle keeps going.

The framework

One sentence: accept honest help, use it to build real capacity, empower others from where you now stand.

It's not charity-as-virtue (which is patronizing). It's not pure self-reliance (which is brittle). It's a circle. Each donation, each engagement, each tool shipped is part of an expanding loop, not a one-way transaction.

Who we are

Dominion Labs is a small Canadian shop. We don't list staff names publicly because the work is what matters; the people doing it are happy to talk on a call but don't need to be on the homepage.

Founded 2025. Apache 2.0 licensed where applicable. No VCs, no investors, no board — just a working ledger.
